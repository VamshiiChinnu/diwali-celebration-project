# 🪔 Diwali Celebration Webpage

A festive-themed mini project developed using HTML5 and CSS3.

## 📌 Project Overview
This project is a simple and visually appealing Diwali celebration webpage.  
It showcases festive elements such as diyas, sparkles, and firecrackers with styled layouts and buttons.

## ✨ Features
- Beautiful Diwali-themed design
- Images of diyas and fireworks
- Styled "View" button
- Clean layout using CSS
- Beginner-friendly structure

## 🛠️ Technologies Used
- HTML5
- CSS3

## 🎯 Purpose
This project was created to practice frontend web development skills including layout design, styling, and image integration.
